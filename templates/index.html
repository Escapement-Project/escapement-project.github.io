Verge

Firmware for NXP's MCU-Link and MCU-Link Pro

Verge takes the place of NXP's firmware on the probe. Any CMSIS-DAP host drives it, as it drives NXP's. One image runs on both probes.

Through probe-rs, Verge writes over SWD at {{ h.ratio }} times the rate of NXP's firmware V3.174. It speaks cJTAG, which NXP's firmware doesn't. And it reads right at clocks where NXP's firmware misreads.

tickwave

Web viewer for mixed-signal captures

tickwave shows a logic or mixed-signal capture inside a web page, beside the text that cites it.

Verge's pages use it. It draws the charts on Verge's page and Verge's measurements. On the measurements page it also opens the recordings the wire figures come from, with every edge the analyser caught on the debug lines.

It converts recordings from other tools too. A Saleae Logic 2 binary export, a sigrok session or a VCD file becomes a tickwave recording in your browser, and nothing is uploaded.
